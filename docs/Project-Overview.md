## Summary

This project focuses on creating a space where I am able to observe network traffic, analyze network events, and understand more about the processes involved in networks.

The tools I use to reach these goals are: Wireshark (a packet analysis tool), Nmap (a network scanner) and Auditd (a daemon which logs network events). These are all incredibly powerful tools that can go extremely low-level, and as such will provide invaluable experience in observing events within my virtual machine's network.

## Wireshark

The first section of the project I focused on was Wireshark.

Using Wireshark, I observed Google pings from my VM, Nmap scans within my VM, and finally an SSH login from my local computer to my VM. 

Whilst simulating and observing these events, I learned many features of Wireshark including it's powerful filtering tool and tools that helped simplify processes for a user (including colour coding and the flowchart tool).
